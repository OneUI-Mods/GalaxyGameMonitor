# Galaxy Game Monitor

ゲームブースターのシステムモニターに、CPUとGPUが端末の最大性能の何％相当で動いているかを表示します。例えばGPUが最大クロックの半分で90％稼働していれば、表示は約45％です。

Vectorなどのlibxposed API 102対応フレームワークでモジュールを有効にし、ゲームブースターを読み込み直してください。ゲームを開いて、ゲームブースターから「システムモニター」を表示します。

Galaxy Game Monitorの「最大クロック基準で表示」をオンにすると換算後の値、オフにすると純正のCPU・GPU使用率を表示します。初期値はオンです。切り替えはモニターの次の更新で反映されます。

更新したモジュールをすぐ反映したいときは「ゲームブースターを再読み込み」を押してゲームに戻ります。ボタンを使うには、Galaxy Game MonitorにRoot権限を許可してください。

CPUとGPUはクロックを基準にした推定値です。必要な計測値が端末から取得できない項目は、従来の値が表示されます。
