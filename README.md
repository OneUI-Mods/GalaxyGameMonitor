# Galaxy Game Monitor

インストールにはAndroid 17（API 37）以降が必要です。

ゲームブースターのシステムモニターに、カーネルが計測したCPUとGPUの使用率を表示します。GPUはAdreno、ExynosのXclipseとMaliに対応します。

現在のGPUクロックを取得できる端末では、GPU使用率の横にMHzで表示します。

「GPUを最大クロック換算で表示」をオンにすると、稼働率に稼働中のクロックと最大クロックの比を掛け、`GPU %` に表示します。Adrenoでは周波数ごとの稼働時間を使います。周波数別の稼働時間を取得できない端末では、計測時のクロックで概算します。換算できない場合は標準の `GPU %` を表示します。

「システムモニターの表示項目」で、FPS、CPU使用率、GPU使用率、GPUクロック、端末全体のメモリ使用率、ゲームのメモリ使用量、バッテリー残量・温度を個別に切り替えられます。温度は小数第1位までの摂氏表示です。

ゲームのメモリ使用量は、そのゲームの各プロセスが使う物理RAMを、共有領域を按分して集計したPSSです。モニターにはGiBで表示します。Androidの詳細計測で、当該プロセスに計上されたグラフィックス領域も含めます。計測にはGalaxy Game MonitorへのRoot許可が必要です。取得できない場合は「—」を表示します。

「1行あたりの項目数」は1〜8から選べます。初期値は4です。「表示項目の並び替え」で各項目を上下に移動できます。ゲーム中は左側の「Game Booster設定」→「システムモニター」から、ゲームを開いたまま同じ設定を変更できます。Game Boosterの全画面設定では上部の「表示項目」から開けます。

「スクリーンショット・画面録画に表示」をオフにすると、端末の画面にはモニターを表示したまま、撮影結果から除外します。初期値はオンです。

Vectorなどのlibxposed API 102対応フレームワークでモジュールを有効にし、ゲームブースターを読み込み直してください。ゲームを開いて、ゲームブースターから「システムモニター」を表示します。

CPUの標準表示は、測定区間でCPUが稼働していた時間の割合です。「CPUを最大クロック基準で表示」をオンにすると最大性能に対する換算値を表示します。

更新したモジュールをすぐ反映したいときは「ゲームブースターを再読み込み」を押してゲームに戻ります。ボタンを使うには、Galaxy Game MonitorにRoot権限を許可してください。

必要な計測値が端末から取得できない項目は、ゲームブースター純正の値を表示します。

### GPUパフォーマンス

Galaxy Game Monitorアプリ、またはゲーム中の **Game Booster設定 → GPUパフォーマンス** から開けます。全画面のGame Booster設定では **表示項目** から変更できます。**GOSのGPUクロック上限を解除** を有効にすると、ゲーム中のGOSによるGPU上限要求を除外します。対応するAdreno端末ではGMUの目標を **システム既定**、**60 FPS**、**120 FPS** から選べます。GMUはGPUクロックを選ぶときにこの値を使い、設定画面には実効値が表示されます。

Vectorでこのモジュールの適用範囲に **Game Optimizing Service** を追加してください。適用範囲の追加直後は、GOSのプロセスが次に起動したときにモジュールが読み込まれます。GMUの変更にはGalaxy Game Monitorのroot権限が必要です。

**ゲーム中もSDHMSのGPU温度制御を使う** は、BZI9のGalaxy S26 Ultraで純正のSDHMSによるGPU温度制御をゲーム中も使用します。GOSの上限解除をオンにすると同時にオンになり、その後は個別にオフにできます。GOSの上限制御に戻すとこの設定はオフになります。SDHMSが要求中のGPU上限は設定画面に表示されます。GPU上限には30秒の有効期限があり、SDHMSが上限を保持している間は更新されます。Galaxy Game Monitorにroot権限がある場合は、SDHMSの接続時に終了済みプロセスが残したGPU上限を確認し、該当する要求を解除します。Vectorの適用範囲に **Samsung Device Health Manager** を追加してください。初回はSDHMSの次回起動時に読み込まれます。
