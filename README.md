# Galaxy Game Monitor

ゲームブースターのシステムモニターに、CPUとGPUが端末の最大性能の何％相当で動いているかを表示します。例えばGPUが最大クロックの半分で90％稼働していれば、表示は約45％です。

Vectorなどのlibxposed API 102対応フレームワークでモジュールを有効にし、ゲームブースターを読み込み直してください。ゲームを開いて、ゲームブースターから「システムモニター」を表示します。従来の表示に戻すにはモジュールをオフにして、ゲームブースターを読み込み直します。

CPUとGPUはクロックを基準にした推定値です。必要な計測値が端末から取得できない項目は、従来の値が表示されます。
