# Galaxy Game Monitor

ゲームブースターのシステムモニターに、Qualcommドライバーが計測したGPU使用率を表示します。測定区間の80％でGPUが稼働していれば、表示は約80％です。

Vectorなどのlibxposed API 102対応フレームワークでモジュールを有効にし、ゲームブースターを読み込み直してください。ゲームを開いて、ゲームブースターから「システムモニター」を表示します。

Galaxy Game Monitorの「CPUを最大クロック基準で表示」をオンにするとCPUの換算値、オフにすると純正のCPU使用率を表示します。初期値はオンです。切り替えはモニターの次の更新で反映されます。

更新したモジュールをすぐ反映したいときは「ゲームブースターを再読み込み」を押してゲームに戻ります。ボタンを使うには、Galaxy Game MonitorにRoot権限を許可してください。

必要な計測値が端末から取得できない項目は、ゲームブースター純正の値を表示します。
