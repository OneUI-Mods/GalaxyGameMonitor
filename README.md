# Galaxy Game Monitor

SamsungのゲームブースターにCPU・GPUの実測値やゲームのメモリ使用量を表示し、GPUパフォーマンスの設定を追加します。

[最新版のダウンロード](https://github.com/OneUI-Mods/GalaxyGameMonitor/releases/latest)

## インストール

1. Android 17以降のGalaxyに、リリースページの署名済みAPKをインストールします。
2. Vectorなど、libxposed API 102に対応したフレームワークでモジュールを有効にします。
3. 使いたい機能に合わせて適用範囲を選びます。初回は、追加したアプリのプロセスが次に起動すると反映されます。

| 使いたい機能 | Vectorの適用範囲 |
| --- | --- |
| システムモニター・ゲーム内設定 | **Game Booster** |
| GOSのGPU上限の表示・解除 | **Game Optimizing Service** |
| SDHMSのGPU温度制御・要求上限の表示 | **Samsung Device Health Manager**（Galaxy S26 UltraのBZI9に対応） |

- 読み込み済みの対象はVectorでホット更新できます。
- ゲームブースターだけを再起動するには、アプリの **ゲームブースターを再読み込み** を使います（rootが必要）。

## 設定を開く

| 場所 | 開き方 |
| --- | --- |
| Galaxy Game Monitorアプリ | モニターの表示を設定。または **GPUパフォーマンス** をタップ |
| ゲーム中 | **Game Booster設定 → システムモニター** または **GPUパフォーマンス** |
| Game Boosterの全画面設定 | 上部の **表示項目** |

## システムモニター

- FPS、CPU・GPU使用率、GPUクロック、端末とゲームのメモリ、バッテリー残量・温度・電力を個別に表示できます。GPUはAdreno・Xclipse・Maliに対応し、表示できる計測値は機種によって異なります。
- **BAT W** はバッテリーの電圧と電流から求めた電力です。プラスは放電、マイナスは充電を表します。給電中も、バッテリーに出入りする分を表示します。
- 項目の順番と1行あたりの項目数（1〜9、初期値4）を変更できます。CPU・GPUは最大クロック基準での表示も選べます。
- **スクリーンショット・画面録画に表示** をオフにすると、端末上のモニターは表示したまま撮影結果から除外します。
- ゲームのメモリ使用量（PSS、GiB）の表示には、Galaxy Game Monitorへのroot権限が必要です。

## GPUパフォーマンス

| 設定・表示 | 動作 |
| --- | --- |
| **GOSのGPUクロック上限を解除** | ゲーム中のGOSのGPU上限要求を除外します。 |
| **ゲーム中もSDHMSのGPU温度制御を使う** | GOSの上限解除をオンにすると自動で有効になります。手動でオフにもできます。GOSの上限制御に戻すと、この設定は自動でオフになります。 |
| **GPU上限** | GOSとSDHMSの要求上限、GPUの実効上限を別々に表示します。 |
| **GMU目標FPS** | 対応するAdreno端末で、システム既定・60 FPS・120 FPSを選べます。変更にはroot権限が必要です。 |

- SDHMSは上限を保持している間、要求を更新します。更新が止まると30秒で期限切れになります。
- root権限がある場合は、接続時に旧SDHMSプロセスが残した上限も確認して解除します。
